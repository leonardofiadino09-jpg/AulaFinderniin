# AulaFinder
Abbiamo ideato AulaFinder per rendere più semplice trovare aule, classi e professori: uno strumento immediato da consultare durante la giornata scolastica. Siamo Edoardo Bastanzetti, Leonardo Fiadino, Francesco Fusetti e Marco Lonati, studenti del Liceo Scientifico G.B. Grassi di Saronno.
